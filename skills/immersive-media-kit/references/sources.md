## How to close the gaps

Ask the user for any of:
- a screenshot of the exact section to copy,
- a short screen recording of the interaction (scroll, press, sound toggle),
- the page's CSS or the animation library names from the browser's developer tools (Network tab, filter for "gsap", "lenis", "three").

Then adapt the closest recipe in this kit rather than guessing.
